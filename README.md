# «Запросто» — мастер на час

Веб-приложение для небольшой компании «мастер на час»: клиент выбирает работы с живым 3D-персонажем, видит цену сразу и оставляет заявку; владелец ведёт заявки в закрытом кабинете. Один экземпляр сайта, одна база и один владелец на компанию.

**Состояние передачи (19.11.2026).** Приложение собрано и проверялось локально в браузере Chromium. Сайт **не развёрнут** на сервере (доступов к хостингу не было) и **не проверялся на реальном телефоне и в iOS Safari**. Что именно проверено и что нет — в [`docs/ОГРАНИЧЕНИЯ.md`](docs/ОГРАНИЧЕНИЯ.md) и в конце [`docs/ЗАПУСК.md`](docs/ЗАПУСК.md).

## Что это

- **Путь клиента.** Шесть категорий (мебель, сантехника, электрика, ремонт, бытовая техника, другое; список и порядок владелец меняет в кабинете), 95 работ с ценой за единицу и почасовая работа мастера. Количество, сложные условия, демонтаж старого, срочный выезд, выезд за город. Корзина и черновик формы переживают перезагрузку. Заявка с адресом, доступом, пожеланием по дате и времени, до трёх фото и согласием на обработку данных. Цену заново считает сервер, суммам из браузера он не доверяет. После отправки открывается приватная ссылка на заявку: состав, расчёт, статус, согласованные мастером цена и время.
- **Кабинет владельца** (`/admin`): «Заявки», «Тарифы», «Компания», «Игра», «Персонажи», «Доступ». Поиск и фильтры, памятка для выезда с инструментом и материалами, итоговая цена и время, статус, приватная заметка, история, фото. Каталог (категории и работы: добавить, переименовать, скрыть, переставить, удалить), цены, доплаты, нормы времени, контакты, работа с организациями, список «не берём», режим игры меняются без программиста.
- **3D.** Шесть персонажей-предметов (шкаф, смеситель, настольная лампа, малярный валик, ящик с инструментами, стиральная машина) с лицом, руками и анимациями приветствия и моргания. Вращение пальцем и мышью, сброс ракурса. Без WebGL сайт показывает постер, и заказ остаётся доступным.
- **Игра.** После заявки можно оттереть пятна ржавчины и налёта на 3D-модели. Режим задаёт владелец: выключена, без скидки или бонус на следующий заказ (бонус применяется вручную).
- **Сайт вокруг.** Страницы услуг и цен, контакты, политика конфиденциальности, источники и лицензии, `sitemap.xml`, `robots.txt`, метаданные, PWA с офлайн-экраном. Светлая и тёмная темы.

## Запуск за 5 минут (локально)

Нужны Node.js 24 и пустая база PostgreSQL 15+ (быстрый способ с Docker описан в [`docs/ЗАПУСК.md`](docs/ЗАПУСК.md)).

```bash
npm ci
cp .env.example .env.local      # в Windows cmd: copy .env.example .env.local
# в .env.local заполните DATABASE_URL, APP_ORIGIN, TOKEN_SECRET (≥ 32 символов), OWNER_PASSWORD (≥ 10 символов)
npm run db:migrate              # схема
npm run db:seed                 # демо-прайс (95 работ), настройки и владелец; заявок нет
npm run dev                     # http://localhost:3000, кабинет: /admin
```

Секрет для `TOKEN_SECRET`: `node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"`. Если `OWNER_PASSWORD` не задан, а база локальная, посев поставит демо-пароль `zaprosto-demo-2026` (только для разработки, перед запуском его надо сменить). Все переменные, сборка, nginx, резервные копии и чек-лист запуска — в [`docs/ЗАПУСК.md`](docs/ЗАПУСК.md).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер разработки |
| `npm run build` | production-сборка (нужны `APP_ORIGIN` и доступная база, подробнее в `docs/ЗАПУСК.md`) |
| `npm run start` | запуск сборки (`-- -H 127.0.0.1 -p 3000`, чтобы слушать только локальный адрес) |
| `npm run typecheck` / `npm run lint` | проверка типов / ESLint |
| `npm test` | vitest: расчёт (юнит) и интеграция с базой `TEST_DATABASE_URL`; имя базы должно оканчиваться на `_test`, **перед прогоном схема в ней стирается** |
| `npm run db:migrate` | применяет новые файлы из `db/migrations/*.sql` (журнал — таблица `schema_migrations`) |
| `npm run db:seed` | досевает демо-данные, ничего не затирая; `-- --overwrite` возвращает демо-значения (на боевой базе не использовать) |
| `npm run db:reset` | удаляет ВСЕ данные, миграции и посев заново; отказывается, если `DATABASE_URL` не на localhost |
| `npm run owner:password -- "пароль"` | задаёт пароль владельца (≥ 10 символов) и закрывает все его сеансы |
| `node scripts/make-icons.mjs` / `make-og.mjs` | пересобирают значки PWA и картинку для соцсетей |
| `python e2e/test_*.py` | сценарии Playwright; сервер должен быть запущен (см. заголовок каждого файла) |

## Публичный API

Все ответы — `Cache-Control: no-store`; изменяющие запросы требуют заголовок `Origin` своего сайта. Ошибка —
`{ error, code, fields? }`, где `fields` — `{ "поле": "сообщение" }` по-русски.

| Маршрут | Назначение |
|---|---|
| `POST /api/uploads` (multipart, поле `file`) | фото → WebP ≤ 1600 px; `{ id, key, width, height, bytes }` |
| `DELETE /api/uploads/[id]` + `X-Upload-Key` | удалить непривязанное фото |
| `POST /api/orders` + `Idempotency-Key` (UUID) | создать заявку: `201 { number, token, url }`; повтор — `200` с теми же данными; тот же ключ с другим содержимым — `409` |
| `GET /api/orders/[token]` | публичный вид заявки (тип `PublicOrder`), опрос раз в несколько секунд |
| `POST /api/game/claim` `{ token }` | бонусный код за игру (один на заявку) |
| `GET /api/admin/photos/[id]` | фото для владельца (cookie сеанса), иначе 401 |
