# «Запросто» — дизайн-система

Название: **«Запросто»** — мастер на час. Запросто — без хлопот: цена видна сразу, заявка в несколько касаний, мастер приезжает и делает. Персонажи — предметы с руками. До 20.11.2026 сервис назывался «Ладно».
Тон: спокойный, конкретный, без восклицаний и продаж. Глаголы действия на кнопках: «Добавить», «Оформить заявку», «Отправить заявку», «Скопировать ссылку».

## Идея
Один смелый элемент — живой 3D-предмет на круглом «подиуме», размеченном как рулетка (сантиметровые деления по кругу; при смене категории кольцо мягко поворачивается). Всё остальное тихое: ровная сетка, крупные кнопки, цены моноширинными по ширине цифрами (`font-variant-numeric: tabular-nums`), а не моноширинным шрифтом.
Не использовать: кремовый фон с терракотой, капслок-надписи над заголовками, строки «А · Б · В», стрелки «→» в кнопках, одинаковые карточки с серой тенью, градиентные пятна.

Цвета категорий (точка в чипе и тон персонажа): Мебель `#C08A55` (дуб), Сантехника `#4E8FCB` (вода), Электрика `#E3B23C` (тёплый свет), Ремонт `#6CC3A0` (мятная краска валика), Бытовая техника `#8E7CE0` (лавандовый, стиральная машина), Другое `#2E57D1` (ящик, фирменный синий). Категории создаёт владелец (до 12), цвет берётся из образцов в кабинете.

Темы: системная по умолчанию (`prefers-color-scheme`), переключатель в шапке (Светлая / Тёмная / Как в системе), выбор сохраняется в localStorage, без вспышки (инлайн-скрипт в `<head>`). Тёмная — не инверсия: поверхности чуть светлее фона, accent светлее.

## Шрифты (next/font/google, self-hosted)
- **Golos Text** (кириллица, создан для интерфейсов) — весь интерфейс. 400/500/600.
- **Unbounded** 500 — только словесный знак «запросто» и H1 главной. Нигде больше.
Шкала (rem): 0.8125 подписи / 0.9375 вторичный / 1 основной / 1.25 H3 / 1.625 H2 / 2.25–3 H1 (clamp). Межстрочный 1.5 для текста, 1.15 для заголовков. Длина строки ≤ 70 символов. Выравнивание — по левому краю.

## Сетка и отступы
- Шаг 4 px; базовые отступы 16 / 24 / 32 / 48. Боковое поле на телефоне 16 px.
- Кнопки и поля: высота ≥ 48 px, зона касания ≥ 44×44, расстояние между нажимаемыми ≥ 8 px.
- Радиусы по иерархии: поля и кнопки 14 px, панели 22 px, чипы — пилюля, подиум — круг. Тени почти не используем: глубина — фоном `--surface` против `--bg` и тонкой линией `--line`.

## Композиция
Телефон (< 900 px):
```
[запросто]                       [тема] [корзина 2]
┌───────────────────────────────────────────────┐
│  3D-сцена ~44vh: персонаж на подиуме-рулетке  │
│  пузырь реплики у головы    [↺ ракурс]        │
└───────────────────────────────────────────────┘
[Мебель] [Сантехника] [Электрика] [Ремонт] [Бытовая техника] [Другое]   ← прокрутка, sticky под шапкой
Сборка шкафа                      1 800 ₽ за шт   [Добавить]
...
──────── нижняя панель (sticky) ────────
3 работы, 5 400 ₽ + по фото            [Оформить]
```
Десктоп (≥ 900 px): две колонки 5/7 — слева липкая сцена на всю высоту окна, справа каталог; корзина — выезжающая справа панель, на телефоне — нижний лист.

## Движение
- UI: motion/react, пружины `stiffness 380, damping 34`; появление позиции в корзине, лист корзины, тост «Удалено — Вернуть».
- 3D: смена персонажа — уход вниз со сжатием 250 мс, появление с лёгким перелётом 400 мс; кольцо рулетки поворачивается.
- `prefers-reduced-motion`: без idle-покачивания и приветствия, смена — простое затухание, моргание оставить редким.
- Не анимировать без причины: одна сцена приветствия при загрузке, остальное — ответ на действия.

## Тексты (примеры)
- Пусто в корзине: «Корзина пуста. Выберите категорию и добавьте работу — цена появится сразу.»
- Материалы: «Цена — только за работу. Материалы и запчасти оплачиваются отдельно.»
- По фото: «Стоимость — по фото. Мастер оценит после просмотра и позвонит.»
- Не берём: «Этого мы не делаем: газовое оборудование. Обратитесь в газовую службу.»
- Ошибки рядом с полем, без извинений: «Укажите телефон — по нему мастер согласует выезд.»

## Организации и офисы (этап 2)
- «Для офисов» (`/dlya-ofisov`) — спокойная страница-документ в стиле `/uslugi`: заголовок H1, короткое вступление, блок «Как мы работаем с организациями» (строки «название — пояснение», условия владельца отдельной плашкой, строка про счёт только при включённой оплате по счёту), работы с отметкой «для офиса» по категориям теми же строками, что на главной. Не баннер: на главной — одна строка под строкой поиска, в шапке — только с 900 px (на телефоне места нет), в подвале — всегда.
- Переключатель «Частное лицо / Организация» — сегментированный: настоящие radio в плашке-дорожке, выбранный сегмент (цвет accent) переезжает пружиной stiffness 380 / damping 34, при reduced motion — сразу. Поля организации появляются под ним коротким сдвигом и затуханием.
- Подписи у организации: «Контактное лицо» вместо «Имя», «Адрес офиса» вместо «Адрес»; ошибки полей говорят так же.
